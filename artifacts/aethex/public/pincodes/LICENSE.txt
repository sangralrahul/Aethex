PIN code -> district and state, used by the delivery check on aethex.in
(src/lib/store/delivery.ts). One file per first two digits of the PIN:
{"d": [districts], "s": [states], "p": {"400001": [district index, state index]}}.

Source: India Post office records, as aggregated in the npm package
india-post-pincode 1.0.0 (one row per PIN code; district and state by majority
vote across offices). Rows whose state doesn't fit the PIN's region were left
out, and state names follow the store's list.
